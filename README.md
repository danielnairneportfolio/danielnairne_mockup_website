# Jamaica Tourism Website

A multi-page website created as for a university course assignment. The project is a mockup of a website made for the Jamaica Tourism Association
## Languages Used

- HTML
- CSS3

## Web Pages

- **Home (`Homepage.html`)**: Introduction to Jamaica, including history, geography, and demographics.
- **Gallery (`Gallerypage.html`)**: Two scenery images and a visitor preference form.
- **Contact (`Contactpage.html`)**: Tourism and emergency contact information.
- **FAQ (`FAQpage.html`)**: Frequently asked questions about Jamaica.

## Running locally

Download the repository, then open `Homepage.html` in your browser. No installation or build process is required.

# Jamaica Tourism Website

A multi-page static website created as part of an **Internet Authoring I** course assignment. The project introduces Jamaican tourism, history, geography, and contact information through a simple HTML and CSS website.

## Technologies

- HTML5
- CSS3

## Pages

- **Home (`index.html`)**: Introduction to Jamaica, including history, geography, and demographics.
- **Gallery (`Gallerypage.html`)**: Two scenery images and a visitor preference form.
- **Contact (`Contactpage.html`)**: Tourism and emergency contact information.
- **FAQ (`FAQpage.html`)**: Common questions about Jamaica.

## Running locally

Download or clone the repository, then open `index.html` in your browser. No installation or build process is required.

## Notes

This is an educational, student-built demonstration, **not an official Jamaica Tourism Association or Jamaica Tourist Board website**. The gallery form has no submission backend and does not store responses. Contact details, historical claims, and other informational content have not been independently verified and may be outdated. The existing content and styling are retained from the course project.
